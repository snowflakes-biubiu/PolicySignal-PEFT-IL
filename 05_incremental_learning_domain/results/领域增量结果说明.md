## 先说结论

数据本身可靠，但这组实验**区分不了 E1/E2/E3 三种方法，也没有观察到遗忘**，所以它不能回答「哪种持续学习方法更好」。能稳妥写进报告的结论只有三条：

- 各方法都能学会各域。
- 累积训练比独立训练的 adapter 好。
- 没有证据表明顺序微调在这个设置下会遗忘。

## 1. 数据自洽性（我复算过）

- 用「3_全量混淆矩阵」重算 Accuracy、Macro-F1、Kappa，与「1_原始测试指标」最大偏差约 2e-16。
- 84 组每组都是 300 条、N/R/W 各 100 条。
- 四种方法在 D1/D1 上的混淆矩阵完全相同，共享 T1 基线成立。
- E4 的旧域结果在 D2–D6 各阶段逐位恒定，说明评估是确定性的，路由也如预期。
- 表4 的 FAA、CSA、AF、BWT、KR 全部与我独立复算一致。

## 2. 各方法的表现

| | FAA | 近似 95% 区间 |
|---|---|---|
| E1 Sequential FT | 0.878 | 0.863–0.893 |
| E2 EWC | 0.876 | 0.861–0.891 |
| E3 Replay | 0.873 | 0.857–0.888 |
| E4 Adapter-CL | 0.848 | 0.832–0.864 |

区间只反映测试抽样噪声，我用混淆矩阵多项分布重采样得到。

- **E1/E2/E3 差距 ≤0.55pp，约 10 个样本，完全在噪声内。**
- **E4 低 2.5–3pp，大概率是真实差异。** 未配对自助法下 E4 与其他三者的差值 95% 区间都不含 0（P≈0.004–0.018）。这仍是单 seed 结果，也没有做多重比较校正。

## 3. 几个容易被误读的地方

**没有可观察的遗忘。**
- 无保护的 E1 的 BWT 是 +0.67pp，KR 是 100.8%。
- E1 在 D1 上随阶段变化：0.823 → 0.833 → 0.873 → 0.843 → 0.870 → 0.863。上升趋势加 5pp 的波动，更像正向迁移加训练和评测噪声，不是遗忘。
- 没有遗忘可缓解，EWC 和 Replay 就没有体现价值的空间。这是实验设置的判别力问题，不是这两种方法本身无效。

**AF 非零不等于遗忘。**
- AF 取历史最大值减最终值，即使真实遗忘为零也会因噪声取最大值而偏正。
- 我用「各域真值固定为 0.88、各阶段独立抽 300 条」模拟，AF 期望约 1.8pp。
- 实测的 1.2–1.5pp 落在这个量级内。独立噪声是上界，实际各阶段评测相关，偏差会更小，所以不能完全归因于噪声，但同样不能当遗忘证据。
- 表5 把任意负 Δ 标成「是否遗忘=是」，最小的 −1.0pp 只对应 3 个样本，这个阈值没有统计意义。

**E4 不是「上限」。**
- 表7 写「E4 因 route 上限参照而系统性偏低」，前后矛盾。E4 是最低的，而且 route 用的是已知测试域标签，是理想化设定。
- E4 低的原因更可能是：每个 adapter 只见过本域 600 条，而 E1 沿链累积了前序域数据。
- E1−E4 对角线差：D2 +5.3pp，D3 +3.7pp，D4 +3.7pp，D5 −0.7pp，D6 +3.0pp，说明跨域数据确实有益。

**对角线差异主要来自域难度，不来自阶段或方法。**
- 只跑了一种域顺序，域难度和阶段位置混在一起。
- E2/E3 的对角线与 E4 的相关系数是 0.89/0.94（E1 是 0.65）。D1 和 D6 对所有方法都偏难。

**类别层面。**
- 各方法 W 类 F1 最低，约 0.81–0.85，R 类最高，约 0.89–0.91。
- D6 模型在 D1–D6 汇总的混淆矩阵里，W→N 是最大误差：E1 76、E2 68、E3 57、E4 80。
- 这个模式四种方法一致，更像任务或标注本身的难点，不是持续学习问题。
- E2 的 R 类 ΔF1 为 −1.5pp，是唯一带符号的类别信号，但每类只有 100 条，不可靠。

**Replay 在 D6 上的当前域表现偏低。**
- E3 在 D6 的对角线是 0.847，E1 是 0.867，E2 是 0.883。
- 与工作簿自述的「D6 新域只过 1.5 遍，其他方法 2 遍」方向一致，是个合理但未检验的可塑性代价假设。差距在噪声边缘。

## 4. 报告口径问题

- **表6 EWC 训练时间可能被低估。** 自述口径是 trainer 的 `train_runtime` 之和，而 Fisher 约 88 秒/阶段不在其中。按此推算，EWC 实际 wall-clock 约 19.5 分钟，不是 12.2 分钟。这是我的推断，需要日志核实。
- **「含 D1」一行口径不一致。** E1 加了 D1（9.7→11.6 分钟），E2/E3/E4 没加，但它们都依赖同一个 T1。
- **模型存储 173 MB 与 145 MB 的差异不明。** 结构同为单 adapter，疑似包含了 checkpoint。显存「未记录」。
- **N/R/W 命名存疑。** 表3 和表7 写 N=规范性、W=鼓励性，我之前审查的 `SYSTEM_PROMPT` 里是 W=肯定性行动指令、N=无指令，需要核对。
- **配置自述与我审查的代码不同。** 自述是 bf16、EWC 的 mean 归一化、Replay 等算力 1200 抽样、文本层截断，我审查的版本不是这样。说明代码已改，但我没有看到新代码，这些改动是否正确实现我无法判断。

## 5. 不能下的结论与建议补做

**不能下的结论：** 任意方法之间的排名（E1/E2/E3）、EWC 或 Replay 有效或无效、Adapter-CL 抗遗忘最强、「某域被遗忘」。

**建议补做（按性价比排序）：**
1. **跑上界和对照。**
   - cumulative 训练（代码里已有）作为上界，用来判断 0.88 是否已经是天花板。
   - 再加「只训 D1 的冻结 T1 模型」在 D2–D6 上的表现，用来量化跨域迁移。
2. **多 seed 加配对检验。**
   - 至少 3 个 seed。
   - 用现有的 24 份 `*_predictions.csv` 做 McNemar 或配对自助法，比我这里的未配对估计更准。
3. **置换域顺序。** 2–3 种顺序，把域难度和阶段效应分开。
4. **让遗忘真正出现。**
   - 用更强的域差异或更长训练。
   - λ 网格在 val 上搜索。
   - 把 Replay 容量设得更小。
5. **修订表述。** 表7 对 E4 的措辞，表5 的遗忘阈值，AF 偏差说明，表6 的成本口径。

我没有看到预测级别的数据，所以上面的置信区间是混淆矩阵层面的近似，偏保守，不是配对检验的结果。
