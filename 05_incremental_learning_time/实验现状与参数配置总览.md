## 0.9 编排脚本的四种模式、状态输入与自愈重试（2026-11-05）

`scripts/run_full_matrix.py` 现在支持 4 种运行模式 + 状态续跑 + 失败自动修复重试。

### 运行模式（`--mode`）

| 模式 | 行为 | 训练单元 | 评估调用 | 测试组 |
|---|---|---|---|---|
| `full`（默认） | 正式训练 + 训完即评 | 17 | 20 | 60 |
| `smoke` | 冒烟：**每个训练最多 2 条样本、1 步**，只验证上下调用与流程；评估每窗口限 2 条 | 17 | 12（E1 不评估） | 42 |
| `train` | 单跑训练，不评估 | 17 | 0 | 0 |
| `eval` | 单跑测试（用已有模型，不训练） | 0 | 20 | 60 |

冒烟模式产物与结果全部隔离在 `artifacts/smoke_tests/`（`continual/` 存模型、`eval/` 存评估），不污染正式结果；E1 的冒烟产物训练结束即删除，故 T2 及以后阶段以**真实 T1 基线**为父模型（需已存在）。冒烟仍受 `gpu_guard` 约束，只能在云端 4090D 跑。

### 状态输入与断点续跑

- `--state logs/full_matrix/summary_<stamp>.json`：读取上次台账，**已成功单元自动跳过**，只补跑失败/缺失部分；
- `--skip-existing`：模型目录或结果文件已存在则跳过（按产物判断）；
- `--resume`：透传给训练脚本，从 Trainer checkpoint 续训（配合 `--state` 处理「被中断」的单元）；
- `--single ewc:3`：只跑单个方法-阶段单元（1 训练 + 1 评估）。

### 错误重连与错误修复

- `--retries N`（默认 1）`--retry-wait S`（默认 5 秒）：子进程失败后按类型自动重试，日志按 `.log` / `.retry2.log` 分开保存。
- 失败原因由日志尾部自动分类，并给出对应处置：

| 分类 | 判定依据 | 自动处置 | 提示 |
|---|---|---|---|
| `conflict` | `FileExistsError` / 「拒绝覆盖」 | 按 `--conflict-policy` 处理后重试 | archive（默认，备份改名不删）/ clean（清理）/ skip（跳过）/ fail |
| `oom` | `out of memory` | 不自动修复，标记该单元失败并继续其它单元 | 需减小批量或换卡 |
| `interrupted` | `KeyboardInterrupt` | 标记失败 | 用 `--resume` 续训 |
| `missing_dependency` | `FileNotFoundError` / 「缺少前阶段」 | 标记失败 | 检查上一阶段模型/状态是否生成 |
| `unknown` | 其它 | 直接重试一次 | — |

- 冲突修复的作用范围按方法精确到该单元的产物：E1 的 `adapter_dir(task)`、E2/E3/E4 的 `{method}_task{N}` 目录、EWC 的 `ewc_state_after_task{N}.pt`、Replay 的 `exemplars_task{N}.jsonl`（不会误删其它阶段或其它种子的产物）。
- 台账 `summary_<stamp>.json` 现在额外记录 `mode / retries / retry_wait / conflict_policy / state_input / single / stopped_methods`，并保留每次重试的 `attempts` 与 `reason`，可直接作为下次的 `--state` 输入。

### 3.5 数据集设计上的三个解释性问题（非 bug，但决定结论）

1. **训练监督与测试 gold 同源**：标签取 `R_1` 自动标注且排除人工 gold，模型在 T2–T5 上继续拟合同一标注器的输出，等价于累积自训练；对同样由该标注器标注的历史窗口准确率上升是构造性结果。
2. **五个窗口被拉成同构子集**：强制 1:1:1 + 逐年均衡配额；论文自然口径为 N 55.6% / W 39.7% / **R 4.7%**，此处 R 被拉到 33%，而 R 是最易判类，整体 Accuracy 偏高且各窗口结构相似。
3. **prompt 不含年份 / era / 任务 ID**：`build_prompt` 只放 `text`（`incremental_common.py:152-163`），模型看不到任何任务边界；T1–T5 对它只是同一任务的 5 批数据，任务路由在推理时也不具备条件。

### 4.4 数据编码与提示词

- 监督方式：`input_ids = prompt_ids + label_ids`，`labels = [-100]*len(prompt_ids) + label_ids`，**只对单个标签 token 计算 loss**；要求标签必须是单 token（`incremental_common.py:166-181`）。
- 训练截断：`MAX_LENGTH - len(label_ids)` = **767** token 尾部截断（`:171-175`）。
- 评估截断：`MAX_LENGTH` = **768** token 尾部截断（`incremental_evaluation.py:252-253`）→ 长样本训练/评估差 1 token。
- Chat template：`tokenizer.apply_chat_template(messages, tokenize=False, add_generation_prompt=True)`（`:158-162`）。
- 用户消息：`待判断政策段落：\n{text}`；系统提示词全文见第 12 节。
- 随机性：只有 `incremental_common.run_training` 显式 `torch.manual_seed(SEED)` + `cuda.manual_seed_all`（`:259-261`）；`continual_training.run_continual_training` 与 `run_evaluation` **无显式种子**，仅靠 Trainer 的 `seed/data_seed`。

## 7. 持续学习指标口径（**两套定义，需统一**）

设 `R_{i,j}` = 训练完 Ti 后在 Tj 测试集上的 Accuracy（j ≤ i，下三角矩阵）。

### 7.1 评估脚本内置（`incremental_evaluation.py:53-119`）

| 指标 | 公式 | 备注 |
|---|---|---|
| ACC | `(1/i)·Σ_{j≤i} R_{i,j}` | 当前阶段对全部已见窗口的平均 |
| BWT | `(1/(i−1))·Σ_{j<i} (R_{i,j} − R_{j,j})` | 正 = 后续训练改善历史任务 |
| Forgetting | `(1/(i−1))·Σ_{j<i} [ max_{k∈{j..i−1}} R_{k,j} − R_{i,j} ]` | 历史最佳**不含当前阶段**，故**可为负**；脚本注释明确 `may be negative` |

### 7.2 《汇报要求.docx》口径（当前 Excel 汇总表采用）

| 指标 | 公式 | 值（E1 / E2 / E3 / E4） |
|---|---|---|
| FAA 最终平均准确率 | `mean_j R_{5,j}` | 0.8627 / 0.8067 / 0.8660 / 0.7487 |
| Final Avg Macro-F1 | `mean_j MacroF1_{5,j}` | 0.8623 / 0.8048 / 0.8655 / 0.7407 |
| AF 平均遗忘程度 | `mean_{j=1..4}[ max_{k∈{j..5}} R_{k,j} − R_{5,j} ]` | 0.0075 / 0.0067 / 0.0017 / 0.0542 |
| BWT | `mean_{j=1..4}(R_{5,j} − R_{j,j})` | +0.0258 / +0.0050 / +0.0375 / −0.0417 |
| KR 历史知识保持率 | `Σ_{j≤4}R_{5,j} / Σ_{j≤4}R_{j,j}` | 103.12% / 100.63% / 104.58% / 94.64% |
| CSA 当前阶段适应能力 | `mean_i R_{i,i}` | 0.8420 / 0.8027 / 0.8360 / 0.7820 |
| FWT | 文档明确「无未训练基线不建议填写」 | 不填 |

**关键差异**：AF 的历史最佳取 `k=j..5`（含最终阶段），因此 **AF ≥ 0**；脚本 Forgetting 取 `k=j..i−1`（不含当前），会出现负值。例：Replay 在 T5 时脚本 Forgetting = **−0.0033**，汇总表 AF = **+0.0017**。两者不是同一个量，引用时必须注明口径。
另外 `A_i = mean_{j≤i} R_{i,j}`，`FAA = A_5`；FAA / CSA / KR 构成的「表现良好」在同分布数据下是算术结果，不能解释为抗遗忘能力。

| P2 | 两套 AF/Forgetting 口径并存 | 第 7 节 | 同一数据出现 −0.0033 / +0.0017 两个数 | 报告中固定一种并注明公式 | 不需要 |
| P2 | 标签同源 `R_1`、类别强制均衡、prompt 无任务信息 | 3.1 / 3.2 / 3.5 | Accuracy 虚高、无真实可遗忘边界 | 视研究目标决定是否重建数据 | 取决于目标 |
| P3 | 单种子、评估无 `set_seed`、训练/评估截断差 1 token | 4.3 / 4.4 / 6.2 | 微小数值漂移（T1 差 1 条） | 补 `set_seed`、统一截断 | 不需要 |
| P3 | 无效输出率恒为 0 且未记录 | 6.3 | 无法评估生成失败 | 评估时记录原始生成与三分类外输出 | 不需要（重评时可加） |
| P3 | Replay 无重加权，预算 9.1%→28.6% | 5.3 | 与基线差异在单种子噪声内（McNemar p=0.70） | 提高预算或过采样后重评 | 可选 |
| P3 | 批量入口无「训练后立即评估 + 门禁」 | `run_all_continual.py:91-145`；`continual_learning_plan.md:69,72` | EWC 在 T2 已明显更差仍训到 T5 | 批量器加评估与门禁 | 不需要 |
| P3 | E1 的 T3–T5 缺逐步骤训练指标日志 | `logs/temporal/` | 可复现性下降 | 补日志或按计划重定义基线 | 不需要 |

### 已经排除的嫌疑（数据没有错）

- 年份越界、era/period 错误、文档日期与 year 不一致：**全部 0**。
- 精确文本重复、跨文件文档重复、train/test 文档交叉：**全部 0**；近重复仅 6 对。
- 测试集跨阶段漂移：**无**（`ParagraphID` 集合稳定）。
- 评估复用缓存 / 模型没换：**排除**（`model_path` 随阶段变化，逐条预测每阶段变化 5–47/300，`logits` 全同 0/300）。
- Replay / EWC Fisher 取到测试集：**排除**（均取自 train）。
- `active_adapters: null` 表示没加载 adapter：**排除**（adapter_config.json 无该字段，且精度 0.74–0.92 说明生效）。

## 10. 缺失数据与限制（仅评估，不补跑）

| 项 | 状态 | 重要性 / 处置 |
|---|---|---|
| 推理时间、峰值 GPU 显存 | 未采集 | 中；如需补齐须在**云端同型号 4090D** 实测，本地 1660Ti 不可比；**不需要重训** |
| E1 分阶段精确训练时长 | 分批训练未逐次计时 | 低；仅给量级估计，不参与精确比较 |
| FWT | 无未来窗口未训练基线 | 文档明确不填 |
| 无效输出率 | 三选一 argmax 强制归类，恒 0 | 中；重评时可记录 |
| 多种子 / 标准差 | 仅 seed=42 单种子 | 中；结论的统计稳健性有限 |
| 阶段间近重复 / 语义重复 | 仅做「去空白后完全相同」精确去重 | 低；实测近重复仅 6 对 |
| 模型选择 | 无验证集、无 best-checkpoint，保存最后权重 | 中；四方法预算一致，可比但非最优 |

## 12. 附：完整系统提示词（`incremental_common.py:38-58`）

```text
角色：你是一名"政策信号一级标注员"。

任务：对给定的中文政策文档段落进行分类标注：

W = 段落中存在对政府/公共部门的肯定性行动指令（包含任何"要/应/负责/建立/加强/推进/组织/指导/监督/落实/制定/完善/开展/实施/安排"等对政府主体布置的任务或授权）。

R = 段落中存在对政府/公共部门的禁止性指令（如"严禁/不得/禁止/停止……（由政府或其部门）"）。

N = 无指令（仅背景介绍、原则口号、定义释义、程序性条款、日期/效力条款、对非国家主体的要求而未同时对政府布置任务或责任的内容）。

受众原则（极其重要）：只统计指向政府及其附属公共机构（包括国务院各部委、地方政府、监管机构、事业单位等）的行动/禁止为"指令"。

仅限制或要求企业/个人/社会组织，而没有同时给政府安排任务或责任 → 记为 N。

若同时出现：例如"企业不得……；主管部门要加强监管……"，则本段视为存在对政府的指令，进入 W 或 R 的判断。

不要只看关键词：是否出现"必须/可以/鼓励/不得"等词不等于对应标签，必须结合主语是否为政府/公共机构与句子功能来判断。

例如："企业必须符合××条件方可办理" → 若仅针对企业且未布置政府任务 → N。

输出要求：仅输出最终的结果W/N/R
```

用户消息模板：`待判断政策段落：\n{text}`（`incremental_common.py:155-157`）。
注意：prompt 中**不包含年份、era、任务编号或任何任务标识**。
