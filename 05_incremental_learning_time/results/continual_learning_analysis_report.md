# 时间增量持续学习：三方法对比分析报告

- **日期**: 2026-11-04
- **分析脚本**: `05_incremental_learning_time/scripts/validation/analyze_continual_results.py`（可复现）
- **数据**: `05_incremental_learning_time/results/temporal/` 20 份累积回测 JSON + 18 份预测 CSV
- **实验设置**: Qwen2.5-1.5B + QLoRA（r16/α32/lr2e-4/2epoch），T1-T5 五个时期各 600 训练/300 测试（N/R/W 均衡），文档级互斥；训练至 TaskN 后在 T1..TN 累积测试集上评估
- **方法**: 朴素顺序微调（基线）/ EWC(λ=5000) / Replay(20条/类/任务) / Adapter-CL(多适配器同时激活)

---

## 一、结论速览

| 方法 | ACC | BWT | Forgetting | T1 终值 | 显著性(vs基线) |
|---|---|---|---|---|---|
| **Replay** | **0.8660** | **+0.038** | **-0.003** | **0.820** | p=0.70，**无差异** |
| 朴素顺序微调 | 0.8627 | +0.026 | +0.005 | 0.817 | — |
| EWC(λ=5000) | 0.8067 | +0.005 | +0.004 | 0.760 | p<0.001，显著更差 |
| Adapter-CL | 0.7487 | -0.042 | +0.054 | 0.687 | p<0.001，显著更差 |

**核心发现**：

1. **Replay（每任务每类 20 条）是最优解**：零遗忘、正向后向迁移（T1 从 0.743→0.820），与基线统计不可分（McNemar p=0.70）。
2. **基线本身几乎不遗忘**（Forgetting 0.005，BWT +0.026）——五个任务共享标签空间与政策文本域，"灾难性遗忘"在这个设定下天然温和。**持续学习方法的门槛不是"防遗忘"而是"别拖后腿"**。
3. **EWC λ=5000 过度正则**：可塑性受损（自己任务的对角线都学不好：T4 0.833 vs 基线 0.920），防遗忘收益也没兑现（T1 0.760 反而最差）——稳定性-可塑性双输。λ 需下调 1-2 个数量级重试。
4. **Adapter-CL 同时激活失败**：R 类召回 100%（500/500）但 W→R 误判 175 条、N→R 114 条——**多适配器叠加放大了"高估 R"倾向**，恰好复现论文 Appendix H 描述的主错误模式。负 BWT 意味着适配器之间相互干扰。

## 八、解释与建议

### 为什么基线不遗忘？
五个任务共享同一标签空间（N/R/W 的判别知识高度共享）与同一文域（中央政策文本），任务差异主要是时间风格漂移。600 样本/任务的 QLoRA 训练不足以覆盖掉早期知识——**正向迁移 > 灾难遗忘**。这也意味着：在这个 benchmark 上声称"抗遗忘"必须以基线为参照，单看绝对遗忘量会得出错误结论。

### 方法层面的建议
1. **Replay 是默认选择**：20 条/类/任务的回放预算已足够（占训练集 10%），成本极低。可以进一步做回放预算消融（5/10/20/50 条）找到下限。
2. **EWC 需要重新调 λ**：λ=5000 把 LoRA 参数锚死在 Task1 附近，可塑性和稳定性双输。建议 λ ∈ {100, 500} 重跑 Task2-5 链（每条约 7 分钟，云端关机前没跑完的话重新开一台即可，模型数据都在本地）。
3. **Adapter-CL 换推理策略**：失败根源是"同时激活全部适配器"的叠加干扰。两个低成本变体值得试：(a) **任务路由**（测试时用任务 ID 选对应适配器——上限即各任务对角线）；(b) **权重合并**（把各 task adapter 平均合并成单一 adapter）。manifest 结构已支持按名加载，改动只在推理侧。
4. **W→R 的结构性难题值得单独立项**：与论文 Appendix H 同源，可在 prompt/训练目标层面引入"W 优先判别"的针对性修正。

### 报告使用注意（局限）
- 测试集为 100×3 均衡集，非自然分布（论文口径 N 55.6%/W 39.7%/R 4.7%），绝对数值与论文不可直接比。
- 标签为语料自动标注（R_1），非人工 gold。
- 每方法仅 1 个随机种子（seed=42）；差异<1 个点的结论（如 replay vs 基线）应解读为"持平"而非"超越"。
- T1 仅 25 个候选文档时代已过——本实验的 T1-T5 数据含年代均衡配额，与自然语料构成不同。
