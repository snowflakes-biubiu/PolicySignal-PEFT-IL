## 全场必须交代的三个口径（开场口头说明或做成页脚）

1. **单 seed**：全部结果 seed=42 单次运行。页面上出现的"95% 误差条"是**二项抽样误差近似**（n=1500 → ±1.8pp；n=1800 → ±1.5pp；单窗口 n=300 → ±4.0pp），**不是跨 seed 方差**。涉及方法间比较的置信区间来自**逐样本配对 bootstrap（2000 次）**。
2. **Joint 口径**：Joint 是"数据全部可用"的**上界参照**，不是持续学习方法——单一模型、无阶段序列，故 BWT / AF / KR / CSA 对它无定义（表中以「—」表示），也**不参与方法排名**。
3. **两个基准不可混算**：时间版与领域版是两套独立流水线（脚本各自一份），**只在同一基准内比较数字**；跨基准只做定性对照（窗口数不同、每窗口 600 训 / 300 测、类别均为 N/R/W）。

## 主线页面

### P1 · 持续学习在这两个基准上最多只有 2pp 空间
*（原：持续学习在这两个基准上没有可争空间）*

**主张**：在 N/R/W 三分类这套任务上，四种持续学习方法与"历史数据全部可用"的联合训练上界之间，最多差 2pp；时间增量上这个差距在统计上不显著。

**要点**
- 时间版：最好的 E2 EWC = 0.8587，Joint-full = 0.8593，差 **0.06pp（不显著，p≈0.97）**
- 领域版：最好的 E1 = 0.8783，Joint-full = 0.8928，差 **1.45pp（显著，p≈0.043）**
- 四种方法之间两两差距 **0.2–0.9pp，全部不显著**
- 所以"选哪个持续学习算法"在这个基准上不是有效问题；**"有没有必要做持续学习"才是**

**图**：两实验 FAA 一览（6 条柱 + Joint-full 水平虚线 + 误差条）
**口径提醒**：领域版那 1.45pp 是真的差异、不是噪声，说"没有空间"要加"最多 2pp"。

### P2 · 比较空间由两个基准、四种方法与两个对照构成
*（原：两个实验、四种方法、两个对照）*

**要点**
- 时间增量：T1 1949–1978 … T5 2013–2023，5 个窗口
- 领域增量：D1 经济与财税金融 … D6 公共安全与应急管理，6 个领域
- 每窗口 / 每域：**train 600（N/R/W 各 200）、test 300（各 100）**；训练 2 epoch = 300 步，QLoRA r16/α32/lr2e-4/max_len 768，seed 42
- 四个方法：E1 顺序微调、E2 EWC（λ=100）、E3 Replay（每域 60 条定额、等算力 1200 抽样）、E4 Adapter-CL（每域一 adapter、按已知域 route）
- 两个对照：**Joint-full**（全部训练数据混合一次训练，1500/1800 步，与 E1 全链等算力）、**Joint-600**（每窗口每类 40 条 = 600 条，300 步，数据量对照）
- 指标：FAA（最终平均准确率）、BWT、AF、KR、CSA；测试集为各阶段下三角

**图**：一张设置示意图（时间轴 vs 领域轴 → 混合 → 两个对照）
**数据出处**：`05_incremental_learning_*/results/*汇总表.xlsx` 的 `0_实验配置与口径`

### P3 · 各方法 FAA 都在上界的 94–99.9% 区间内

**要点**
- 时间版：E1 98.8%｜E2 **99.9%**｜E3 99.2%｜E4 94.2%
- 领域版：E1 98.4%｜E2 98.1%｜E3 97.8%｜E4 **95.0%**
- 绝对差距：时间 0.06–1.00pp（E4 例外 5.00pp）；领域 1.45–2.00pp（E4 4.50pp）
- 视觉上"几乎贴顶"的原因是 Joint-full 本身也只有 0.86 / 0.89 —— **天花板不高**

**图**：分组柱状图（两组并排），每组 4 柱 + Joint-full 水平线，误差条 ±1.8 / ±1.5pp
**口径提醒**：误差条是抽样误差，不是 seed 方差（见口径 1）。

### P4 · 没有观察到遗忘，后向迁移反而为正

**要点**
- 时间版 AF：E1 0.0175 / E2 0.0133 / E3 0.0142（E4 结构性 0）
- 领域版 AF：E1 0.0127 / E2 0.0153 / E3 0.0120
- BWT 全为正：时间 +0.0167 / +0.0133 / +0.0367；领域 +0.0067 / 0 / +0.0060
- KR 全部 ≥ 100%（时间 102.03% / 104.50%；领域 100.76% / 100.00% / 100.69%）
- **对照噪声基线**：AF 的抽样量级约 ±1.5pp，而观测值 1.2–1.8pp —— 遗忘信号本身就处在噪声边缘

**图**：左 = E1 历史矩阵热力图（下三角，5×5 / 6×6）；右 = AF / BWT 柱状图 + 噪声带
**口径提醒**：AF 用 `max_{k=j..T}`（含最终阶段）定义，恒 ≥ 0；脚本另有一个可负的 `Forgetting` 定义，**报告只能用一个**（本 PPT 用前者）。

### P5 · 方法间差距小于噪声，且排名在两个基准间翻转

**要点**（配对 bootstrap，2000 次，逐样本对齐）

| 对比 | 时间版 | 领域版 |
|---|---|---|
| E1 − E2 | −0.93pp，CI [−2.13, +0.27]，跨 0 | **+0.22pp**，CI [−1.00, +1.44]，跨 0 |
| E1 − E3 | −0.33pp，CI [−1.80, +1.13]，跨 0 | +0.56pp，CI [−0.78, +1.94]，跨 0 |

**口径提醒**：排名翻转本身不是新发现，而是"差异在噪声内"的直接证据，不要解读为"某方法在某类任务上更强"。

### P7 · 决定表现的是数据总量，不是方法

**要点**（阶梯图数据）
- 时间版：Joint-600 **0.8007** → E4 0.8093 → E1 0.8493 → E3 0.8527 → E2 0.8587 → Joint-full **0.8593**
- 领域版：Joint-600 **0.8411** → E4 0.8478 → E3 0.8728 → E2 0.8761 → E1 0.8783 → Joint-full **0.8928**
- **从 600 条到 3000/3600 条，提升 5.2–5.9pp**；而换方法只在 0.2–0.9pp 内移动
- 数据量贡献（UB − Joint-600）：时间 **+5.87pp**、领域 **+5.17pp**

**图**：阶梯图（横轴按数据规模排序），标注"数据量区间"与"方法区间"两段色块
**结论句**：方法选择的影响（<1pp）比数据规模的影响（5–6pp）小一个量级。

### P8 · E4 偏低源于数据不共享，加上 route 口径的特殊性

**要点**
- E4 ≈ Joint-600（时间 0.8093 vs 0.8007，差 0.86pp；领域 0.8478 vs 0.8411，差 0.67pp）
- 机制：E4 每个域只训练自己的 600 条，**不共享跨域知识**，容量上等同于"每域 600 条数据"
- route 推理是**已知测试领域**的理想化设定（`adapter_inference=route`）：每个测试样本始终由对应 adapter 预测，因此 **AF≡0、KR≡100% 是结构性的**，不是"抗遗忘能力强"
- 所以 E4 的定位是"已知领域标签的路由上限参照"，不能与 E1–E3 同表排名遗忘指标

**图**：E4 与 Joint-600 两点重合的柱状图 + 一张 route 机制示意（测试域 → task_j adapter）
**口径提醒**：任何把 E4 的 AF=0 当作"最优"的排名都是错的。

### P9 · 正向 BWT 是数据量红利，不是抗遗忘

**要点**
- E1 的**第一个窗口**（只用该窗口 600 条训练）：时间 T1 = **0.7667**、领域 D1 = **0.8233**
- Joint-full 在**同一个窗口**（用 3000/3600 条混合训练）：时间 T1 = **0.8133**、领域 D1 = **0.8700**
- 两者都提升 **+4.67pp**，方向、幅度完全一致
- 说明：混合训练让"首个窗口"也变好了 —— 这是**跨窗口数据互补**，不是"抵抗遗忘"；BWT 为正的根源在此
- 推论：**该基准不具备"遗忘"这一现象**，用它来比较抗遗忘算法缺乏区分度

**图**：双柱对比（E1 首窗口 vs Joint-full 首窗口，两实验并列）+ 右侧小字"同为 +4.67pp"
**数据出处**：`表1` 主表 T1/D1 列 + `表1` 补充段 Joint 行

### P10 · 两个基准的差异来自窗口难度，不来自方法

**要点**（Joint-full 逐窗口 / 逐域，单一模型测得，排除方法干扰）

| 时间版 | T1 | T2 | T3 | T4 | T5 |
|---|---|---|---|---|---|
| ACC | 0.8133 | 0.8533 | **0.8267** | **0.9133** | 0.8900 |

| 领域版 | D1 | D2 | D3 | D4 | D5 | D6 |
|---|---|---|---|---|---|---|
| ACC | 0.8700 | 0.9067 | **0.9133** | 0.9033 | 0.8867 | **0.8767** |

- 时间版极差 **8.7pp**（T3 最低 0.8267，T4 最高 0.9133），且非单调
- 领域版极差 4.7pp，呈"D 形"（中间高、两端低）
- 同一批方法在两个基准上表现不同，主要由**窗口/域本身的难度分布**决定
- 时间版整体略低（0.8593 vs 0.8928）也可由窗口难度解释，而非时间漂移

**图**：两条折线（Joint-full 逐窗口 ACC），共用 0.80–0.92 纵轴
**口径提醒**：折线是单一模型的跨测试集表现，与 E1–E4 的对角线口径不同，只用于比较窗口难度。

### P11 · 两个待查现象，都不改变主结论

**要点 ①：Replay 在最后窗口系统性低 3.0pp**
- 时间版 T5：E3 0.8600 vs Joint-full 0.8900 = **3.00pp**
- 领域版 D6：E3 0.8467 vs Joint-full 0.8767 = **3.00pp**
- 两个独立基准上**恰好都是 3.0pp**，不像随机波动；E3 的回放池 300 条 / 每域 60 条对"最新窗口"覆盖最薄（新域过境 1.5–1.9 遍）

**要点 ②：最终模型的 W/N 偏置方向相反**（全量聚合混淆矩阵，Gold 行 × Pred 列）

| | N→W | W→N | 解释 |
|---|---|---|---|
| 时间版 E1（1500 条） | **70** | **24** | 倾向把"无指令"判成"肯定性指令" |
| 领域版 E1（1800 条） | **33** | **76** | 反方向，倾向把"肯定性指令"判成"无指令" |
| 时间版 Joint-full | 45 | 40 | 偏置明显缓解、接近均衡 |
| 领域版 Joint-full | 39 | 60 | 方向同 E1，但幅度减半 |

- 顺序训练**放大了类别偏置**，联合训练部分抵消
- 该偏置不影响主结论（两方向都在总准确率里被平均掉），但值得单独排查

**图**：左 = 两个基准的 N↔W 错判计数对比柱；右 = E1 与 Joint-full 的偏置差值
**待办**：先看 N→W 错判样本的文本特征（是否短文本 / 无动词），再检查校准（temperature scaling）

### P12 · 顺序微调成本最低，E4 部署最重
*（原：成本与部署）*

**要点**

| | 时间版训练 | 领域版训练 | 额外状态 | 模型存储 |
|---|---|---|---|---|
| E1 顺序微调 | **9.1 min** | **9.7 min** | 无 | 82 / 173 MB |
| E2 EWC | 17.2 min | 12.2 min | **+175 MB Fisher** | 82 / 145 MB |
| E3 Replay | 11.0 min | 9.6 min | +1.25 MB 回放池 | 82 / 145 MB |
| E4 Adapter-CL | 9.4 min | 10.1 min | 无 | **292 / 406 MB（多 adapter）** |
| Joint-full（参照） | 8.9 min | 10.3 min | 无 | 29 MB |

- E1 零额外状态、成本最低，且性能与上界无显著差距 → **工程上是最优解**
- E2 的 Fisher 状态是存储与时间的主要开销，换来的性能提升不显著
- E4 需要维护 N 个 adapter 且依赖已知测试域，部署复杂度最高

**图**：成本-性能散点（横轴训练时间，纵轴 FAA），四点 + 上界虚线
**口径提醒**：Joint 的训练时间与分阶段口径不可直接相减，仅作量级参照。

### P13 · 结论受限于单 seed 与两套流水线的差异
*（原：局限）*

**要点**
- **单 seed**：全部 seed=42，无跨 seed 方差；页面上的 CI 是抽样误差与配对 bootstrap，不能替代多种子
- **测试集规模**：每窗口 300 条，单窗口分辨率仅 ±4pp；只有聚合（1500/1800 条）才有 ±1.5–1.8pp 的分辨率，1pp 量级的结论必须靠聚合口径
- **Joint 配置**：固定 2 epoch（与 E1 全链等算力）；Joint-600 的 300 步与 Joint-full 的 1500/1800 步**不等算力**，其 5–6pp 差距混合了"数据量"与"步数"两个因素，未做等步数版本
- **流水线差异**：时间版与领域版脚本各自分叉（EWC 归一化实现、Replay 预算参数不同），故跨基准只做定性对照
- **数据版本**：时间版当前训练语料指纹 `52384663cd` 与历史 E1–E4 的 `5f45fc66f6` 不同；但**测试集逐条同源**（1500 条文本 100% 一致），故评估对比有效
- **切分方式**：按段落划分，同文档可跨 split（时间 32 篇、领域 339 篇文档级重叠，段落级 0 重叠）

**图**：风险清单表（每条给"影响范围"与"是否影响主结论"两列）

### P14 · 基准缺乏区分度，下一步先补数据量曲线与多 seed
*（原：结论与下一步）*

**结论（一句话）**：这套基准缺乏区分度——顺序微调已经接近联合训练上界，**不需要保存历史数据**；**数据量比方法重要一个量级**。

**下一步（按性价比排序）**

| 优先级 | 任务 | 目的 | 成本 |
|---|---|---|---|
| 1 | **Joint 数据量曲线**：600 / 1200 / 1800 / 3000（领域到 3600） | 把 P7 的"数据量主导"从 2 个点扩成曲线，直接给出饱和点 | 4–5 次训练，各 300–1800 步，约 1 小时 |
| 2 | **Joint-full / E1 / E2 多 seed（3–5 个）** | 把 ±1.5pp 的抽样 CI 换成真实的 seed 方差，判定 1.4–2.0pp 差距是否稳健 | 3 方法 × 4 seed，约 3 小时 |
| 3 | **构造"会产生遗忘"的设定**：更强的域差异、更长/更高 lr 训练、更小的回放池 | 让 AF/BWT 出现可比信号，再检验 E2/E3 是否真的有效 | 需重新设计数据，1–2 天 |
| 4 | **查 W/N 偏置**：先看 N→W 错判样本，再检查校准（temperature scaling） | 解释 P11 的反向偏置，判断是否影响部署 | 分析为主，半天 |

**收尾一句**：如果 1、2 两项确认"数据量饱和点 < 全量"，那么这套任务上**持续学习的合理结论就是"不做"**，而报告价值转为"数据规模—性能"的定量关系与偏置诊断。

### B4 · 指标定义与两套 AF 口径
- FAA = mean_j R_{T,j}；BWT = mean_j(R_{T,j} − R_{j,j})；AF(含最终) = mean_j[max_{k=j..T} R_{k,j} − R_{T,j}]；KR = ΣR_{T,j}/ΣR_{j,j}；CSA = mean_i R_{i,i}
- **两套遗忘定义**：脚本 `Forgetting`（可负，对历史最佳但不含最终阶段）vs 工作簿 `af_including_final`（恒 ≥ 0）。**本 PPT 全程用后者**，若引用脚本字段需显式声明。
- Joint 的 BWT/AF/KR/CSA 无定义（无阶段序列），评估器以 `missing_history_stages` + `metrics_partial=True` 标注。

### B5 · 本阶段口径修正与数据版本
- EWC 惩罚归一化从 `Σ/(P×n_anchor)` 修正为 `Σ/n_anchor`（旧实现把惩罚稀释 6 个数量级，等于关闭 EWC）
